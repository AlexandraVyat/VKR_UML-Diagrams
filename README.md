# Создание UML-диаграмм для ВКР

## О проекте

Репозиторий содержит материалы лабораторной работы по дисциплине «Инструментальные средства программирования».

Работа посвящена разработке UML-диаграмм для выпускной квалификационной работы на тему создания веб-приложения для адаптивного обучения математике и анализа образовательных достижений учащихся начальной школы.

## Содержание репозитория

В репозитории представлены пять UML-диаграмм:

1. **Use Case**
2. **Class**
3. **Sequence** 
4. **State** 
5. **Activity**

Для каждой диаграммы представлены исходный код PlantUML и готовое графическое изображение.

Дополнительно в репозитории размещены программный код модели классов (model.py), текстовый отчёт и презентация лабораторной работы.
